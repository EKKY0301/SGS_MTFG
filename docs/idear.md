# Idear

## Objetivo
Proponer soluciones tecnológicas que respondan a los problemas y necesidades
identificados en las etapas anteriores.

## Ideas Propuestas
- Sistema web accesible desde cualquier dispositivo
- Interfaz clara y fácil de usar
- Centralización de datos en una sola plataforma
- Separación de roles (administrador / socio)
- Gestión básica de eventos y pagos

## Selección de la Solución
Se optó por desarrollar un **sistema web** como solución principal, debido a su
accesibilidad, escalabilidad y facilidad de mantenimiento.

## Justificación
Un sistema web permite a las asociaciones reducir la dependencia de procesos
manuales y mejorar significativamente la gestión de la información.
